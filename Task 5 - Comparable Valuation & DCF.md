# Comparable Valuation & DCF Analysis

## Objective

Evaluated a company's value using two widely used valuation approaches: Comparable Company Analysis and Discounted Cash Flow (DCF) analysis.

## Analysis Performed

- Analysed the company's historical financial performance.
- Identified relevant comparable companies.
- Compared companies using key financial and valuation metrics.
- Calculated valuation multiples.
- Developed a DCF-based valuation framework.
- Forecast future cash flows.
- Applied an appropriate discount rate.
- Estimated terminal value.
- Derived an implied enterprise value and equity value.
- Compared valuation results across methodologies.

## Comparable Company Analysis

Comparable Company Analysis was used to estimate the company's valuation based on how similar publicly listed companies are valued by the market.

Key multiples considered include:

- EV / EBITDA
- EV / Revenue
- Price / Earnings (P/E)

The analysis compares the target company's financial characteristics with selected peer companies to derive an indicative valuation range.

## Discounted Cash Flow Analysis

DCF analysis was used to estimate the intrinsic value of the business based on its expected future cash flows.

The analysis involved:

1. Forecasting future operating performance.
2. Estimating future free cash flows.
3. Applying a discount rate.
4. Calculating the present value of projected cash flows.
5. Estimating terminal value.
6. Calculating enterprise value.
7. Adjusting for relevant balance-sheet items to derive equity value.

## Key Valuation Concepts

### Enterprise Value

Enterprise Value represents the value of the operating business available to all providers of capital.

### Equity Value

Equity Value represents the value attributable to the company's shareholders after accounting for relevant debt and cash adjustments.

### WACC

Weighted Average Cost of Capital (WACC) represents the blended required return expected by the company's debt and equity providers and is used as the discount rate in the DCF analysis.

### Terminal Value

Terminal Value captures the estimated value of the business beyond the explicit forecast period.

## Valuation Framework

The analysis combines:

- Market-based valuation through comparable companies
- Intrinsic valuation through DCF
- Financial forecasting
- Discounted cash-flow analysis
- Sensitivity to key assumptions

## Key Takeaway

Using both comparable-company valuation and DCF provides two complementary perspectives on business value: one based on prevailing market valuations of similar companies and the other based on the company's expected future cash-generating ability.
